# dc-cli brand

## Metaphor

A host frame around a guest. Matches the product: host-global wrappers around official `@devcontainers/cli`. Same idea as the site’s double-bezel cards.

## Mark

Production files (use these):

- `logo-mark.svg` — `currentColor` icon
- `logo-wordmark.svg` — mark + `dc-cli`
- `logo-on-dark.svg` — baked dark plate
- `logo-on-white.svg` — baked white plate

Concepts in `concepts/` are exploration only. Do not ship them.
