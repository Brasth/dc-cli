# v0.23.0 — Phosphor Console

The dc workspace board now follows the Phosphor Console design: services first, compact branding, warm off-white text, and a phosphor-green accent.

- Responsive layouts for wide, medium, narrow and minimal terminals, including 40×12.
- Selected-service details beside the list on wide terminals and below it on medium terminals.
- Shortcut footers, scrolling lists, and separate mouse-hover and keyboard-selection markers.
- Consistent styling for fleet, logs, top, networks, recovery, workspaces, actions, activity and trust review.
- Clear loading, refresh, failure, confirmation and success feedback; terminal-safe names, tab-expanded logs and monochrome support.

Existing command targets, shared-action trust, `--no-start` execution and destructive confirmations remain intact. The shell fallback menu is unchanged.

Update with `dc upgrade`. Compiled packages include `dc-tui` and `dc-actions` for macOS and Linux, on Intel/AMD and ARM64.

Design notes and previews: https://github.com/Brasth/dc-cli/blob/v0.23.0/docs/tui-phosphor-console.md
