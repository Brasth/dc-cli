# dc-cli demo tapes (VHS)

Reproducible terminal walkthroughs for marketing videos. Run with [VHS](https://github.com/charmbracelet/vhs) on a machine with Docker/Colima and dc-cli installed.

## Prerequisites

```bash
brew install vhs
# dc-cli installed with --with-cli
export DC_TUI_NO_SPLASH=1
```

Use a demo project with `.devcontainer` at `~/demo/dc-app` and a compose-only project at `~/demo/dc-compose`.

## Record all walkthroughs

```bash
cd scripts/demo-tapes
for tape in *.tape; do vhs "$tape"; done
```

Output lands in `../../site/public/videos/` per each tape's `Output` line.
